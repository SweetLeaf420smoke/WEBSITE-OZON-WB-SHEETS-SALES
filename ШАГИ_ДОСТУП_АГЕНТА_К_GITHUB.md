# Как дать агенту доступ к GitHub (маленькими шагами)

## Где лежит токен (для агента)

- **Общий файл для всех проектов:** `/Users/sick/Documents/Cursor/.env.github` — там `GH_TOKEN=...`
- В этом проекте тоже есть **`.env`** с тем же токеном (для push). Для новых проектов: скопировать из `.env.github` или подгрузить: `export $(cat /Users/sick/Documents/Cursor/.env.github | xargs)`

---

## Шаг 1 — от тебя: положить токен в проект

**Вариант А:** Ты помнишь/сохранял значение токена CURSOR 1 (`ghp_...`).  
→ В папке проекта создай файл **`.env`** с одной строкой:
```bash
GH_TOKEN=ghp_сюда_вставить_токен
```

**Вариант Б:** Значение токена нигде не сохранял (GitHub его больше не покажет).  
→ Создай **новый** token (classic): https://github.com/settings/tokens/new  
  Note: `website-push`, галочка **repo** → Generate → **скопируй** `ghp_...` и сразу вставь в `.env`:
```bash
GH_TOKEN=ghp_новый_токен
```

Файл **`.env`** уже в `.gitignore` — в репозиторий не попадёт.

Когда будет готово — напиши «шаг 1 готов», сделаю шаг 2 (push с подгрузкой `.env`).
