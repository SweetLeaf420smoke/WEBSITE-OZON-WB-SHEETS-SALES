# Один раз выполни в своём терминале (Cursor → Terminal)

## Вариант А (через gh — проще)
В папке проекта выполни — создаст репо и сразу запушит:
```bash
cd "/Users/sick/Documents/Cursor/WEBSITE OZON WB SHEETS SALES"
gh repo create WEBSITE-OZON-WB-SHEETS-SALES --public --source=. --remote=origin --push --description "Лендинг: таблица перераспределение по складам WB"
```

## Вариант Б (если без gh)
1. Создай пустой репо: https://github.com/new → имя **WEBSITE-OZON-WB-SHEETS-SALES**, Public, без README.
2. Затем в терминале:
```bash
cd "/Users/sick/Documents/Cursor/WEBSITE OZON WB SHEETS SALES"
git push -u origin main
```

После этого подключение к GitHub завершено.
