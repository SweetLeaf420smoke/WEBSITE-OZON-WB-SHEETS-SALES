# PROJECT_STATE

## Workflow
After any code change always continue:
edit -> push -> deploy -> run test -> fetch real result -> report

## Mandatory checks
DATA CHECK
FLOW CHECK
UI CHECK

## Reporting
Always report:
- task
- files changed
- push status
- deploy status
- test run
- actual result
- conclusion

## Do not do
- never stop after code edit
- never claim done without checking actual output
